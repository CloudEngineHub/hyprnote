You can create a Mistral API key in Free mode without a credit card. Free access has usage and rate limits; creating a key does not give every model unlimited capacity.

Sources checked October 29, 2026. The screenshots below were captured in September 2026.

## **What you need before getting started**

You need a Mistral account and access to [Studio](https://console.mistral.ai). Follow any verification prompts shown during signup. Mistral's [current key-creation quickstart](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key/) lists no credit card requirement for Free mode.

Before sending confidential text, review your training preferences and [Mistral's retention controls](/blog/mistral-data-retention-policy/). Training opt-out and Zero Data Retention are separate: [ZDR requires pay-as-you-go, approval, and a supported stateless endpoint](https://help.mistral.ai/en/articles/347612-can-i-activate-zero-data-retention-zdr). A free key does not establish ZDR.

## **How to generate your Mistral API key (step by step)**

1. Go to [console.mistral.ai](https://console.mistral.ai), Mistral's Studio console, and create an account
2. Complete any account verification requested by Studio
3. Once inside Studio, navigate to **API Keys** in the left sidebar
4. Click **Create new key**

![Mistral Studio API Keys page with the Create new key button highlighted](anarlog/blog/library/products/mistral/console/2026-09-08-api-keys-create-button.png)
Source: [Mistral Docs, Activate Studio and generate an API key](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key/), captured September 2026

5. Give the key a name, set an expiration date (Mistral now prompts for one on every new key), choose a connector access scope, and confirm

![Mistral's create new API key dialog with name and expiration fields](anarlog/blog/library/products/mistral/console/2026-09-08-create-key-modal.png)
Source: [Mistral Docs, Activate Studio and generate an API key](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key/), captured September 2026

6. Copy the key immediately and store it somewhere safe. Mistral won't show it again

## **Mistral API rate limits on the free plan**

Check the [Admin Panel Limits page](https://admin.mistral.ai/plateforme/limits) for the model you intend to call. The [current usage documentation](https://docs.mistral.ai/admin/billing-usage/usage-limits) lists completion throughput per model, including requests per second and tokens per minute. Free mode also has included monthly usage. Organization and Workspace spending caps can stop access independently of throughput.

A `429` means a rate limit was exceeded. Use bounded retries with backoff for a temporary burst; check the model's limits and remaining allowance before repeatedly retrying. Adding payment details does not mean unlimited throughput.

Mistral's [August help article](https://help.mistral.ai/en/articles/698531-why-am-i-hitting-api-rate-limits-and-how-do-i-increase-them) still describes automatic tiers based on cumulative billed usage. Its newer [Subscription documentation](https://docs.mistral.ai/admin/billing-usage/subscriptions) describes included usage shared across Studio, API, and Vibe Code, with prepaid pay-as-you-go for additional usage. Use the limits and subscription settings shown for your Organization rather than budgeting from a universal free-tier quota or tier threshold.

## **Mistral API pricing: how much does it cost**

For chat models, input and output tokens are priced separately. The table shows standard USD rates from the [API pricing page](https://docs.mistral.ai/inference/pricing), checked October 29, 2026. It does not describe your included allowance or guarantee Free-mode access to either model.


| Model | Input per million tokens | Output per million tokens |
| --- | --- | --- |
| Mistral Small 4 | $0.15 | $0.60 |
| Mistral Large 4 (public preview) | $0.70 | $2.10 |


For example, one million input tokens plus 100,000 output tokens costs $0.21 at the listed Small 4 rates, before any allowance, discounts, taxes, or other services. Longer transcripts and repeated summaries add usage. Check the selected model and billing settings before automating requests.

Plans can include monthly API usage; additional consumption with pay-as-you-go draws from prepaid credits. Batch and cached-input pricing differ from standard requests. Check the exact model's rates rather than assuming a fixed monthly bill.

## **Which Mistral model should you use**

For a first request, Mistral's quickstart uses `mistral-small-latest`. Confirm that your account has capacity for it. For repeatable application behavior, choose a versioned General Availability model and review its [lifecycle](https://docs.mistral.ai/inference/model-lifecycle) instead of assuming a `latest` alias will keep the same price or behavior. Public Preview models can still receive silent updates.

[Small 4's model card](https://docs.mistral.ai/models/mistral-small-4-0-26-03) lists `mistral-small-2603` and Apache 2.0 for the model weights. [Large 4](https://docs.mistral.ai/models/mistral-large-4-0) is a public preview under the Mistral Ecosystem Open Weight License. Do not generalize Small's license to every Mistral model. Hosted API usage also follows Mistral's service terms.

Test a candidate against representative notes, latency requirements, and your budget. A larger model is an option to evaluate, not a guarantee of better meeting summaries.

## **How to use your Mistral API key in your project**

Keep the key on a trusted machine or backend, outside source control. For a local test, set it as an environment variable:

```bash
export MISTRAL_API_KEY="your-key-here"
```

The value above is a placeholder. For a real key, use your approved secret tooling; avoid exposing it in shell history, logs, screenshots, or browser-side code. Rotate it if exposed.

Test it with a curl call:

```bash
curl https://api.mistral.ai/v1/chat/completions \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "model": "mistral-small-latest", "messages": [{"role": "user", "content": "Hello"}] }'
```

If you get a JSON response with a `choices` array, the key worked for that request. A `401` calls for checking the variable, expiration, and key status. A `429` calls for checking limits and usage; regenerating the key does not raise your Organization's allowance.

For a Python project that uses a local `.env` file, `python-dotenv` can load it at runtime. Exclude that file from version control:

```python
from dotenv import load_dotenv
import os

load_dotenv()
api_key = os.getenv("MISTRAL_API_KEY")
```
